# 🏠 مشطّب (Moshateb) — نظام إدارة تشطيب الشقة ومتابعة الصنايعية

> **تطبيق ويب متكامل، سريع، ومبني لمساعدة أصحاب الشقق في إدارة رحلة التشطيب من الصفر حتى استلام المفتاح بأعلى جودة هندسية وأفضل تحكم في الميزانية.**

---

## 🌟 مميزات التطبيق

1. **إدارة الصنايعية والمقاولين (Craftsmen Management)**:
   - تسجيل بيانات الأسطوات (سباك، كهربائي، نقاش، سيراميك، جبس بورد، محارة، نجارة، ألوميتال).
   - تدوين المصنعية الإجمالية المتفق عليها، العربونات، المبالغ المتبقية، والتقييم.
   - حفظ شروط التعاقد الفنية (مثل: استلام بالليزر، كبس بالبار، نظافة المكان).

2. **سجل الدفعات وسندات الصرف الفورية (Payments & Receipts)**:
   - تتبع كل دفعة وعربون مع بند الصرف وطريقة السداد (كاش، إنستاباي، فودافون كاش، تحويل بنكي).
   - توليد **إيصال صرف مالي معتمد** قابل للطباعة مباشرة بمقاس ورقي نظيف، ومشاركته بضغطة زر.
   - تصدير كامل المعاملات المالية إلى ملف **Excel / CSV** بنقرة واحدة (مع دعم كامل للغة العربية UTF-8 BOM).

3. **متابعة الخامات والمشتريات (Materials & Supplies Tracker)**:
   - تتبع فواتير الموانين ومحلات السباكة والكهرباء والدهانات.
   - رصد حالة التشوين والتسليم في الشقة (تم التوريد / في انتظار التوصيل).
   - حساب إجمالي المصروف الفعلي للشقة (مصنعيات + خامات).

4. **المخطط الزمني الهندسي لمراحل التشطيب (10 Finishing Stages)**:
   - تسلسل هندسي صارم لمنع تداخل الصنايعية وتجنب تكسير الشغل بعد إنهائه.
   - قوائم فحص (Checklists) إلزامية لكل مرحلة، مع نصائح ذهبية وتحذيرات من الأخطاء الشائعة.

5. **دليل الاستلام الهندسي (Inspection & QC Guide)**:
   - خطوات فحص عملية لكل تخصص بدون الحاجة لخبرة سابقة.
   - قائمة الأدوات والعدة اللازمة للمعاينة (ميزان مياه، ليزر، فيشة تيست، قدة).
   - تنبيهات بأشهر الحيل والأخطاء الكارثية لتجنب دفع المصنعية في شغل معيب.

6. **حاسبة تقدير الخامات الذكية (Material Calculators)**:
   - حاسبة كميات النقاشة (السيلر، معجون الحوائط، بستلات التشطيب النهائي).
   - حاسبة السيراميك والمونة (الأمتار، نسبة الهالك، الكراتين، مادة اللصق).
   - حاسبة أسلاك الكهرباء (لفات الإنارة 1.5 مم، البرايز 2.5 مم، المكيفات 4 مم).

7. **رسائل واتساب السريعة الجاهزة (WhatsApp Templates)**:
   - قوالب جاهزة للتأكيد على المواعيد، طلب لستة الخامات، إرسال إشعار بسداد دفعة، أو تنبيه بملاحظة فنية مطلوب تعديلها فوراً.

8. **تخزين محلي آمن ومجاني (Offline LocalStorage)**:
   - كافة بياناتك تُحفظ تلقائياً في متصفحك دون الحاجة لقاعدة بيانات أو اشتراكات شهرية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Hosting Target**: Vercel / GitHub Pages / Static Hosting

## 🚀 التشغيل محلياً (Run Locally)

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### الخطوات:
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. بناء نسخة الإنتاج والتأكد من خلو الأخطاء
npm run build

# 4. معاينة نسخة الإنتاج محلياً
npm run preview
```

## 📦 النشر على GitHub (Deploy to GitHub)

1. **تهيئة مستودع Git محلياً**:
```bash
git init
git add .
git commit -m "Initial commit: منصة مشطّب لإدارة تشطيب الشقة"
```

2. **إنشاء مستودع جديد على GitHub**:
   - اذهب إلى [GitHub](https://github.com/new) وأنشئ مستودعاً جديداً (مثلاً: `moshatab`).
   - لا تقم بتهيئة README أو .gitignore من واجهة GitHub لأنها موجودة وجاهزة بالفعل في المشروع.

3. **ربط المستودع ورفعه**:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/moshatab.git
git push -u origin main
```

## ⚡ النشر على Vercel (Deploy to Vercel)

المشروع مُهيأ بالكامل للنشر الفوري على **Vercel** بفضل ملف `vercel.json` المُضمن:

### الطريقة الأولى: من خلال موقع Vercel (موصى بها)
1. سجّل دخولك إلى [Vercel](https://vercel.com).
2. اضغط على **"Add New..."** ثم اختر **"Project"**.
3. اختر مستودع المشروع من حسابك على **GitHub** (`moshatab`).
4. الإعدادات التلقائية المكتشفة:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. اضغط **Deploy**. في أقل من دقيقة سيكون موقعك فعالاً ومتاحاً على رابط مجاني مثل `https://moshatab.vercel.app`.

### الطريقة الثانية: عبر Vercel CLI
```bash
npm i -g vercel
vercel
```
